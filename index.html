အထူးခြားဆုံး နေ့ရက် ✨

31.7.2007 ဆိုတဲ့ ဒီနေ့ရက်မှာ လောကကြီးထဲကို ရောက်ရှိလာခဲ့တဲ့ နှင်းအိလှိုင်အတွက် အမှတ်တရ မွေးနေ့လေး စတင်ပါပြီ။

Memory 01 / 10

၁၉ နှစ်ပြည့် မွေးနေ့မင်္ဂလာပါ 🩵

အသက် ၁၉ နှစ်ပြည့်သွားတဲ့ နှင်းအိလှိုင်ရေ... ဘဝခရီးလမ်းမှာ အမြဲတမ်း ပျော်ရွှင်မှုတွေနဲ့သာ လမ်းခင်းနိုင်ပါစေလို့ ဆုတောင်းပေးပါတယ်။

Memory 02 / 10

အပြုံးမပျက်ပါနဲ့ ✨

မင်းရဲ့ မျက်နှာပေါ်က အပြုံးလေးတွေက ဘေးနားကလူတွေကို အမြဲတမ်း အားဖြစ်စေပါတယ်။ အဲ့ဒီအပြုံးလေးတွေ အမြဲတမ်း တောက်ပနေပါစေ။

Memory 03 / 10

အိပ်မက်များဆီသို့ 🌟

" နှင်းအိလှိုင် " 🩵

အသက် ၁၉ နှစ်ပြည့်သွားတဲ့ အမှတ်တရ မွေးနေ့လေးမှာ စိတ်၏ချမ်းသာခြင်း၊ ကိုယ်၏ကျန်းမာခြင်းတို့နဲ့ ပြည့်စုံပြီး လိုအင်ဆန္ဒမှန်သမျှ အကုန်ပြည့်ဝပါစေလို့ ဆုတောင်းပေးပါတယ်။

31.7.2007 မှာ မွေးဖွားခဲ့တဲ့ မင်းလေးဟာ ငါတို့အတွက်တော့ အမြဲတမ်း ခင်ဖို့ကောင်းပြီး တန်ဖိုးရှိတဲ့ သူငယ်ချင်းတစ်ယောက်ပါ။ ၁၂.၅.၂၀၂၅ ကတည်းက စတင်ခဲ့တဲ့ တို့တွေရဲ့ ခင်မင်မှုလေးကိုလည်း အမြဲတမ်း တန်ဖိုးထားပါတယ်။

ရှေ့ဆက်ရမယ့် ဘဝခရီးလမ်းမှာလည်း အခက်အခဲမှန်သမျှကို ရဲရဲဝံ့ဝံ့ ကျော်ဖြတ်နိုင်ပြီး ကိုယ်မှန်းမျှော်ထားတဲ့ အိပ်မက်တွေ၊ အောင်မြင်မှုတွေကို အရယူနိုင်ပါစေ။ မျက်နှာပေါ်မှာလည်း အပြုံးလေးတွေ အမြဲတမ်း ပိုင်ဆိုင်နိုင်ပါစေ။

ထာဝရ ပျော်ရွှင်ပါစေ သူငယ်ချင်းလေး... 🎁🩵
